# Supermarket Shopping & Loyalty App

**Solo project** · Advanced Mobile Application Development module, University of Technology, Mauritius (2026)

A Flutter app built for a supermarket case study, with two kinds of users:
- **Customers** shop online, earn loyalty points and use digital vouchers.
- **Admins** manage stock, with changes showing up in real time.

## Features
- Login and registration with separate admin and customer roles
- Real-time product and stock updates (Supabase streams)
- Shopping cart and checkout
- Loyalty rewards, digital vouchers and an interactive weekly brochure
- Admin dashboard for stock management

## Tech
Flutter · Dart · Supabase

## Run it locally
1. Create a Supabase project.
2. In `lib/supabase_config.dart`, replace `YOUR_PROJECT` and `YOUR_SUPABASE_ANON_KEY` with your own values.
3. `flutter pub get` then `flutter run`.
